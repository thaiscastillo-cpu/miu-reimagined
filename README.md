# MiU — Diseño completo

Sitio publicado: https://miu-reimagined.vercel.app

Este repositorio publica **tal cual** el diseño completo de MiU hecho en Claude Design (`index.html`).
Es una página estática: todas las pantallas, textos y datos de ejemplo son los del diseño original.

- `index.html` — el diseño completo (único cambio: la tarea grupal dice "Proyecto" en lugar de "Proyecto grupal").
- `docs/` — guía del workshop y plan de implementación.

La rama `nextjs-supabase` guarda una versión alternativa en Next.js + Supabase; no está publicada.
